# SQL Static Trainer

SQL Static Trainer is a small, browser-only practice application for learning
SQLite `SELECT` syntax. Version 0.1 uses one frozen hospital dataset and five
original exercises. It has no backend and sends no learner query to a
project-controlled server.

PR01 contains only the repository foundation and fixture checks. SQL execution,
content loading, evaluation, the complete practice interface, and progress
storage are introduced by the later pull requests listed in the development
bundle.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run test:run
npm run build
npm run preview
```

The canonical frozen assets are exposed at `fixtures/target/public/` by the repository’s text-only `fixtures` link to the original development bundle and can be checked without installing packages:

```bash
node scripts/check-fixtures.mjs
```

## Dialect and v0.1 limitations

- Dialect: SQLite.
- Learner work is limited to a single read-only `SELECT`; a leading `WITH` is
  allowed when it produces a `SELECT`.
- The release contains one dataset and five exercises.
- Progress is local to the browser; there are no accounts or synchronization.
- The reference SQL ships to the browser because this is a practice tool, not a
  secure assessment system.
- There is no backend, authentication, analytics, rich editor, content authoring
  system, or support for another SQL dialect.
