# SQL Static Trainer v0.1 — Codex Development Bundle

This bundle is the executable development plan for a minimal, browser-only SQL
practice application.

It is **not** the finished application. It freezes the scope, supplies the toy
database and five exercise artifacts, defines the target contracts, and splits
implementation into six reviewable pull requests.

## Product outcome

A learner opens a static website, selects one of five exercises, writes a
SQLite query, runs it in the browser, sees the result, checks it against a
reference result, and has completion saved locally.

## Frozen v0.1 boundary

Included:

- Vite + React + TypeScript static application.
- One bundled SQLite database.
- Five original read-only `SELECT` exercises.
- Browser-side SQL execution using `sql.js`.
- Fresh database state for every learner execution.
- Result-set comparison rather than SQL-string comparison.
- Exercise navigation and local completion state.
- Static production build and deployment runbook.

Excluded:

- Backend, accounts, classes, instructors, assignments, and analytics.
- Content authoring UI or automatic exercise generation.
- DML/DDL grading.
- Multiple SQL dialects or databases.
- Authentication or exam-grade secrecy.
- Hints generated by an LLM.
- Monaco, CodeMirror, Tailwind, component libraries, and other nonessential
  dependencies.
- Copying the exercise corpus or UI of sql-practice.com.

## Release definition

the manual smoke script passes in a production build, and
`memos/FINAL_HANDOFF.md` records the deployed URL or the explicit reason
deployment was deferred.
