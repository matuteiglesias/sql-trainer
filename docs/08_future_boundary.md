# Future Boundary

This file prevents v0.1 from absorbing later product layers.

## v0.2 — Content Factory

A separate future bundle may cover:

- authoring schema and content compilation;
- many datasets;
- hundreds of exercises;
- coverage matrix;
- linting and duplicate detection;
- generated variants;
- editorial review workflow;
- content release manifests.

v0.1 should expose clean exercise and evaluator contracts, but must not build
these systems now.

## v0.3 — Teaching Layer

A separate future bundle may cover:

- accounts;
- classes and rosters;
- assignments and playlists;
- instructor analytics;
- server-side attempt events;
- grading;
- LMS integration;
- hidden assessment material.

v0.1 progress remains local and anonymous.

## Trigger for the next bundle

Only begin v0.2 planning after:

- v0.1 release gate is closed;
- at least one real practice session has been run;
- friction and missing-content observations are recorded;
- no unresolved runtime defect prevents repeated use.
